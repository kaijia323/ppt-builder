【忠于原文】
- 数字、单位、名称照抄原文；引用的段落里必须包含要点中的数字。
- 保留原文语气：原文写"需/须"，不要写成"已实现"；原文写"预计/计划/拟"，要保留这些词。原文写"备选/视情况启用"的手段，要写明是备选。
- 保留原文的专有提法（如"四位一体"不要改成"四库一体"，"多层级"不要扩大成"多组学"）。
- 不要把不同句子拼成一个新事实：A 句的范围词不能套到 B 句的对象上（如"覆盖多数乡镇"与"面向部省市县四级"不能合成"部省市县乡镇四级"）。
- 不用原文没有的程度词（显著、全面、领先、确保等）。
- 不得把只适用于某个上下文的句子当作整页结论。

【反例与正例】（示例来自不同领域，只说明写法，不要套用其中的内容）
✗ 标题："本系统仅负责数据采集"
  问题：原句出自"与上下游系统的分工"，单独拿出来当结论，会让听众以为系统不做分析和展示。
✓ 标题："边界清晰：负责采集与分析，主数据由财务系统提供"

✗ 标题："课程共12讲，采用翻转课堂，期末考核占40%"（三件事并列，没有结论）
✓ 标题："翻转课堂替代纯讲授，期末考核降至40%"（一个结论，事实支撑）

✗ 要点："须保留生产版与测试版两套环境并支持一键回切；新版本先在2个城市试点1个月"（一条讲了两件事）
✓ 拆成两条："保留生产版与测试版两套环境，可一键回切"；"新版本先在2个城市试点1个月再推广"

✗ 要点："不承担A模块、B模块、C模块、D模块、E模块……的开发"（逐项罗列其他单位的任务名称）
✓ 要点："不承担平台原有模块的开发与运维"（只保留与责任、费用相关的关键排除项）
